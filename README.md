# 随机表情包插件 (nekroagent-random-emoji)

NekroAgent 插件：收到「随机表情包」指令或机器人被戳一戳时，从本地表情包图库或图床随机选取一张图片发送到当前聊天。

版本：**0.2.0**　作者：**NTidal**　适配器：**onebot_v11 / sse / discord / qqbot_openclaw**（戳一戳触发仅 onebot_v11）

---

## 功能

- 📁 **本地图库**：递归扫描自定义目录中的图片（jpg / jpeg / png / gif / webp / bmp / ico / svg）随机发送；
  默认目录为插件数据目录下的 `emojis/` 文件夹，把图片放进去即可。
- ☁️ **图床支持**：配置远程图片 URL 列表（每行一个），随机选取下载发送；本地无图时自动回退，反之亦然。
- ⚡ **三种零延迟触发**（跳过 LLM 思考，不消耗 token）：
  - **戳一戳**：机器人被戳一戳时回一张随机表情包（按 用户+频道 维度冷却，用户之间互戳不响应）；
  - **直连关键词**：消息完全等于触发词（默认「随机表情包」等）时直接发送；
  - **斜杠命令**：`/随机表情包`（别名 `/random_emoji`、`/来张图`、`/发张图`、`/发张表情包`）。
- 🤖 **AI 自主调用**：对 AI 说"来张图 / 发张表情包"，模型调用 `random_emoji` 工具完成发送。
- 🧠 **上下文可控**：发出的图片默认**不写入** LLM 对话历史（仅供用户观看）；触发消息是否记录也可配置。

---

## 安装

1. 将 `random_emoji.py` 放入 NekroAgent 插件目录，或在 NA WebUI 打包上传安装。
2. **完全重启 NekroAgent**（消息钩子与命令在启动时注册）。
3. （可选）向插件数据目录下的 `emojis/` 文件夹放入表情包图片，或在插件配置中填写图床 URL 列表。
4. 在群里发送「随机表情包」测试。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `EMOJI_DIR` | 空 | 本地表情包目录：绝对路径直接用；相对路径相对于插件数据目录；留空用默认 `emojis/` 文件夹（自动创建） |
| `REMOTE_EMOJI_URLS` | 空 | 图床图片 URL 列表，每行一个；留空则不使用图床 |
| `PREFER_LOCAL` | `true` | 优先本地图库；本地无图时自动回退到图床 |
| `ENABLE_DIRECT_TRIGGER` | `true` | 启用直连触发：命中触发词直接发送并跳过 LLM 思考 |
| `TRIGGER_KEYWORDS` | `随机表情包` 等 4 个 | 直连触发词列表，消息文本**完全等于**其中之一即触发 |
| `RECORD_IMAGE_TO_CONTEXT` | `false` | 是否把发出的图片写入对话历史供 LLM 参考；默认只发给用户 |
| `RECORD_TRIGGER_MESSAGE` | `true` | 是否把触发词消息记录到对话历史（`true`：记录但阻止 LLM 回复；`false`：完全不记录） |
| `ENABLE_POKE_TRIGGER` | `true` | 被戳一戳时回随机表情包（仅 OneBot v11） |
| `POKE_COOLDOWN` | `10` | 戳一戳冷却秒数（同一用户同一频道）；`0` 表示无冷却 |

## 使用方式

**四种触发方式**

| 方式 | 触发条件 | 说明 |
| --- | --- | --- |
| 戳一戳 | 机器人**被戳一戳** | 零延迟回图；仅 OneBot v11；受 `POKE_COOLDOWN` 冷却限制 |
| 直连关键词 | 消息**完全等于**触发词 | 默认 `随机表情包` / `来张图` / `发张图` / `发张表情包`，零延迟 |
| 斜杠命令 | `/随机表情包` | 别名 `/random_emoji`、`/来张图`、`/发张图`、`/发张表情包`，可带 `local`/`remote` 参数 |
| AI 调用 | 对 AI 说"随机表情包 / 来张图" | AI 调用 `random_emoji` 工具；工具支持 `source` 参数指定 `local` / `remote` |

> 想要**纯图片零文字**：使用直连触发（不加 `/` 前缀）。斜杠命令的输出会带命令系统前缀。

**来源选择逻辑**

按 `PREFER_LOCAL` 决定候选顺序，一种来源无图/失败时自动切换另一种；两个来源都不可用时提示先添加图片或配置图床。

## 常见问题

**发了「随机表情包」没反应**
确认 `ENABLE_DIRECT_TRIGGER` 开启、消息文本与触发词**完全一致**（带标点/前后缀不算）；或插件数据目录下没有图片且未配置图床。

**戳一戳没有反应**
- 仅 OneBot v11 适配器支持；其他适配器请用关键词或命令触发；
- 用户之间互戳不会触发，只有**戳机器人**才回图；
- 检查 `POKE_COOLDOWN` 冷却（默认同一用户 10 秒内只回一次）。

**AI 不主动发图**
对 AI 直接说"来张图 / 发张表情包"即可；AI 的自主调用取决于人设与对话语境。

**如何添加表情包**
把图片（支持子文件夹递归）放进插件数据目录 `NTidal.random_emoji/emojis/`，或在 `EMOJI_DIR` 指定自定义目录，
或填写 `REMOTE_EMOJI_URLS` 使用图床。

---

## 说明

- 戳一戳识别依赖 OneBot v11 的 `notify/poke` 事件；部分协议端需开启对应事件上报。
- 图片仅随机选取发送，不做去重；连续触发可能重复，可加大冷却或自行扩充图库。
- 图床 URL 每次随机抽取一张，下载失败会尝试另一种来源。
